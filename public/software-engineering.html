about the rpl program

The Software Engineering (RPL) department focuses on developing the ability to design, create, and maintain computer-based applications according to industry needs. Here, students will learn the complete software development workflow — from requirements analysis, interface design, programming, to testing and documentation — with a hands-on practical approach that prepares them to become professional developers. With an up-to-date curriculum and collaborative projects, the RPL department instills creativity, logic, and problem-solving skills, so its graduates are ready to compete in the ever-evolving digital era

What is Learned in RPL?

Programming

Learn to build applications and websites using popular languages such as Java, Python and PHP, as well as the latest technologies (Laravel, React)

Database

Design and manage data storage systems for applications/websites using professional tools (MySQL, PostgreSQL)

DevOps

Learn how to develop and operate applications efficiently using modern tools (Docker, Jenkins)

Facilities in the RPL Department

  • High-End Computer Lab

    PCs with i7-13700k processors, 16 GB RAM, 512GB SSD and RTX 3060 Ti GPUs, so programming and design applications run smoothly

  • Professional Tools

    Up-to-date software such as Visual Studio Code, Git, Docker, and official JetBrains licenses (IntelliJ, PyCharm)

  • Fast & Stable Internet

    100 Mbps connection for cloud computing learning, streaming material and online collaboration

  • Industry Certificates

    Access to Microsoft, Cisco and Oracle training and certification exams for students
